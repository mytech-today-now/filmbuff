# MCP Integration

This directory is kept intentionally small so `.augment/` stays inside the repo budget.

Canonical local paths:
- `.augment/mcp/servers.json` — CLI-side MCP server configuration
- `.vscode/mcp.json` — editor/runtime MCP wiring
- `.vscode/MCP_SETUP.md` — setup and troubleshooting

Long-form MCP guidance was moved to `augment-extensions/domain-rules/mcp/`.

Use that module for configuration patterns, examples, and implementation notes while preserving this path for compatibility.
