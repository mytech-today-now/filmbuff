# Tasks: Self-Destruct Oven SNL Skit

## Phase 1: Pre-Writing (Research & Planning)

### Task 1.1: Research SNL Format
- [ ] Review 3-5 recent SNL corporate satire sketches
- [ ] Analyze pacing and structure
- [ ] Note common comedic devices
- [ ] Identify typical runtime vs. page count ratio
- **Estimated Time**: 1 hour
- **Dependencies**: None
- **Deliverable**: Research notes

### Task 1.2: Character Development
- [ ] Create 4-6 character profiles
- [ ] Assign distinct personality archetypes
- [ ] Choose accent/speech pattern for each
- [ ] Define character motivations
- [ ] Identify potential character conflicts
- **Estimated Time**: 1.5 hours
- **Dependencies**: Task 1.1
- **Deliverable**: Character profiles document

### Task 1.3: Outline Story Beats
- [ ] Map out 8-10 major comedic moments
- [ ] Structure three-act progression
- [ ] Plan escalation arc
- [ ] Design surprising ending
- [ ] Identify callback opportunities
- **Estimated Time**: 1 hour
- **Dependencies**: Task 1.2
- **Deliverable**: Beat sheet

## Phase 2: Writing

### Task 2.1: Write Act 1 (Setup)
- [ ] Write opening scene description
- [ ] Introduce characters
- [ ] Establish the fire problem
- [ ] Present "feature vs bug" conflict

- **Estimated Time**: 1 hour
- **Dependencies**: Task 1.3
- **Deliverable**: Act 1 draft

### Task 2.2: Write Act 2 (Escalation)
- [ ] Write debate sequences
- [ ] Develop character-specific arguments
- [ ] Insert corporate jargon satirically
- [ ] Build to peak absurdity
- [ ] Include 2-3 major laugh moments
- [ ] Target: 90-150 seconds (1.5-2.5 pages)
- **Estimated Time**: 2 hours
- **Dependencies**: Task 2.1
- **Deliverable**: Act 2 draft

### Task 2.3: Write Act 3 (Resolution)
- [ ] Craft surprising twist
- [ ] Write thought-provoking conclusion
- [ ] Add final comedic button
- [ ] Target: 30-60 seconds (0.5-1 page)
- **Estimated Time**: 1 hour
- **Dependencies**: Task 2.2
- **Deliverable**: Act 3 draft

### Task 2.4: Add Stage Directions
- [ ] Insert blocking notes
- [ ] Add timing/pause indicators

- **Dependencies**: Tasks 2.1, 2.2, 2.3
