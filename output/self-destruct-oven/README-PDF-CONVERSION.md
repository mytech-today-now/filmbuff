That's it! The script will:
1. Convert the Fountain file to HTML

2. Select "Save as PDF"
3. Choose where to save
4. Done!

## 🐛 Troubleshooting

### "Python is not recognized"
**Solution**: Install Python from https://python.org
- Or use online converters (Fountain.io)
- Or use desktop software (Highland 2, Fade In)

### "File not found"
**Solution**: Make sure you're in the correct directory
```
cd "G:\_kyle\temp_documents\GitHub\screenplays\ai-prompts\self-destruct-oven"
```

### "HTML looks wrong in browser"
**Solution**: 
- Use a modern browser (Chrome, Firefox, Edge)
- Make sure CSS is enabled
- Try a different browser

### "PDF has wrong margins"
**Solution**: When printing to PDF:
- Set paper size to "Letter" (8.5" × 11")
- Set margins to "Default" or "None"
- Enable "Background graphics"
- Disable "Headers and footers"
