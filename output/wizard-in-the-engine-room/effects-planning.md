## PRACTICAL EFFECTS (On-Set)

### 1. WARP CORE MAGICAL SPARKLES

**Scene:** Engine room - when Clif casts "Velocitas Maxima Stellarum"

**Effect Description:** Magical sparkles swirl around the warp core

**Method:**
- **Primary:** Rotating LED light projector with sparkle/star pattern
- **Secondary:** Handheld sparkle wands (off-camera crew)
- **Enhancement:** Post-production VFX overlay

**Equipment:**
- LED star projector (rotating)
- Colored gels (blue/purple/white)
- DMX controller for timing

**Timing:** 3-4 seconds, synchronized with staff gesture

**Safety Notes:** 
- Low voltage LEDs only
- Secure mounting of projector
- No strobe effects (epilepsy concern)

**Cost:** $150 (projector rental)  
**Rehearsal Required:** Yes - timing with actor

### 4. FLOO POWDER FLAME EFFECT (HERO EFFECT)

**Scene:** Conference room - Clif and Heidi's disappearance

**Effect Description:** Green flames erupt when Floo powder hits the ground

**Method Options:**

**OPTION A: Flash Paper + Green Flame Powder (Traditional)**
- Professional flash paper
- Copper-based green flame colorant
- Controlled ignition by licensed effects technician
- Duration: 2-3 seconds

**OPTION B: LED + Fog Machine (Safer Alternative)**
- Green LED light panel (floor-mounted)
- Fog machine for smoke effect
- Synchronized activation
- Duration: 3-4 seconds

**RECOMMENDED:** Option B (LED + Fog) for safety and repeatability

**Equipment (Option B):**
- Green LED panel (2' x 2')
- Low-lying fog machine
- Fog fluid (water-based, non-toxic)
- DMX controller for synchronization
- Green glitter (thrown by actor for visual)

**Timing:** 
- Actor throws glitter: 0 seconds
- Fog begins: 0.5 seconds
- LED ramps up: 0.5-2 seconds
- Actors step into effect: 2 seconds
- LED peak: 2-3 seconds
- Fade out: 3-4 seconds

**Safety Notes:**
- Fire extinguisher on set (even for LED option)
- Fire safety officer present
- Fog machine tested for allergies
- Ventilation confirmed
- Rehearsal required (3+ times)
- Mark safe standing positions
- Non-slip floor surface

**Cost:** 
- Option A: $200 (flash paper + colorant + safety)
- Option B: $400 (LED panel + fog machine rental)

**RECOMMENDED BUDGET:** $400 (Option B)

**Rehearsal Required:** YES - Multiple rehearsals mandatory

## SAFETY PROTOCOLS

### Fire Safety (Floo Powder Effect)

**Required Personnel:**
- [ ] Fire safety officer on set
- [ ] Effects supervisor
- [ ] First aid personnel

**Required Equipment:**
- [ ] Fire extinguisher (ABC rated, 10 lb minimum)
- [ ] Fire blanket
- [ ] First aid kit
- [ ] Ventilation system operational

**Safety Procedures:**
- [ ] Clear 10-foot safety perimeter marked
- [ ] Actors briefed on emergency stop signal
- [ ] Rehearsal completed successfully (3+ times)
- [ ] Floor surface checked (non-slip, fire-resistant)
- [ ] Emergency exits clear
- [ ] Communication system tested (director to effects)

### Electrical Safety

**All Electrical Effects:**
- [ ] GFCI-protected outlets used
- [ ] All connections waterproofed (cauldron effect)
- [ ] Low voltage systems only (12V or less preferred)
- [ ] Cables secured and marked
- [ ] No trip hazards
- [ ] Emergency power cut-off accessible

### Fog Machine Safety

- [ ] Water-based, non-toxic fog fluid only
- [ ] Ventilation system operational
- [ ] Cast/crew checked for respiratory sensitivities
- [ ] Fog dissipation time tested
- [ ] No fog near electrical equipment (except waterproof)

### Rigging Safety (Floating Candles)

- [ ] Ceiling mounts tested (3x weight capacity)
- [ ] Fishing line tested (50 lb test minimum)
- [ ] Candles secured to prevent falling
- [ ] Area below candles marked
- [ ] Daily inspection of rigging

## CONTINGENCY PLANS

### If Fog Machine Fails:
- Use handheld fog canisters (backup)
- Rely more heavily on VFX smoke in post
- Adjust lighting to compensate

### If LED Panel Fails:
- Use practical colored lights (gels)
- Enhance in post-production
- Adjust actor timing

### If Staff/Wand Lights Fail:
- Use off-camera flashlights
- Add glow effects in post-production
- Have backup batteries ready

### If Safety Concerns Arise:
- STOP immediately
- Reassess with fire safety officer
- Switch to VFX-only solution if necessary
- Never compromise safety for a shot
