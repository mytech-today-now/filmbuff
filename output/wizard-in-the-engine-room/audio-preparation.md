## AUDIO TECHNICAL SPECIFICATIONS

### File Format
- **Format:** WAV (uncompressed)
- **Sample Rate:** 48kHz
- **Bit Depth:** 24-bit
- **Channels:** Stereo (some ambiences) or Mono (most SFX)

### Delivery Requirements
- All files clearly labeled (SFX-01_Engine_Ambience.wav)
- Organized in folders by category
- Cue sheet provided (this document)
- Backup copies on separate drive

### Mixing Notes
- Dialogue is priority - SFX should not overpower
- Engine ambience should be felt, not heard (low frequency)
- Hero effects (Floo powder) can be prominent
- Red alert klaxons should be urgent but not painful
- All SFX should have clean fades (no clicks/pops)

## AUDIO TIMELINE

### Week 1: Sourcing & Preparation

**Monday:**
- Research and select sound libraries
- Purchase/license needed sounds
- Download all files

**Tuesday:**
- Organize files into categories
- Rename files to match cue sheet
- Create project folder structure

**Wednesday:**
- Edit sounds as needed (trim, fade, loop)
- Create ambience loops
- Test all files for quality

**Thursday:**
- Create preliminary mix (rough timing)
- Identify any missing sounds
- Source additional sounds if needed

**Friday:**
- Finalize all sound files
- Deliver to sound mixer
- Provide cue sheet and notes

### Production Week

**During Shoot:**
- Record room tone on set (1 minute each location)
- Record any practical sounds (footsteps, prop handling)
- Note any additional sound needs

### Post-Production Week

**Monday-Tuesday:**
- Sound mixer receives footage
- Sync all sound effects to picture
- Begin mixing

**Wednesday-Thursday:**
- Refine mix levels
- Add any additional foley
- Director review

**Friday:**
- Final mix adjustments
- Deliver final audio mix
- Archive all source files

## SOUND MIXER NOTES

### Key Moments Requiring Special Attention

**1. Floo Powder Disappearance (2:45-2:50)**
- This is the climax of the sketch
- Sound should build from powder throw to full effect
- Layers: whoosh + flames + swirl + disappearance
- Should feel magical and impressive

**2. Ship Failure Sequence (3:10-3:25)**
- Chaotic but not muddy
- Multiple elements: lurches, klaxons, sparks, dialogue
- Prioritize dialogue clarity
- Build tension with layering

**3. Romantic Moment (1:45-1:50)**
- Subtle, don't overpower
- Gentle magical sounds
- Optional music should be very low

### Mixing Philosophy
- This is a comedy sketch - clarity over realism
- Sound effects support the comedy, don't distract
- Star Trek sounds should be recognizable (audience familiarity)
- Magical sounds should be whimsical, not dark

## CONTINGENCY PLANS

### If Sounds Are Not Available
- Have backup library sources identified
- Be prepared to use similar sounds with processing
- Sound designer on call for custom creation

### If Budget Is Reduced

- Reduce optional elements (music, extra ambiences)

### If Timeline Is Compressed
- Focus on essential sounds first
- Use pre-made loops for ambiences
- Simplify complex sound layers
