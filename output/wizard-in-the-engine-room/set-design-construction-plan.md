# Set Design & Construction Plan
## "Wizard in the Engine Room"

---

## Overview

**Number of Sets:** 2  
**Style:** SNL-style parody sets (recognizable, comedic, high-quality)  
**Build Timeline:** 2 weeks  
**Budget Estimate:** $3,500-5,000

---

## SET 1: ENGINE ROOM (Primary Set)

### Design Concept
**Fusion of Star Trek Engineering and Hogwarts Magical Workshop**

### Dimensions
- **Width:** 16 feet
- **Depth:** 12 feet  
- **Height:** 10 feet (to accommodate floating candles)

### Layout

```
        [BACK WALL - Star Charts & Constellation Maps]
                    
[WARP CORE]              [CAULDRON]           [SPELL BOOK SHELF]
  (Left)                 (Center-Right)            (Right)
    |                         |                       |
    |                    [CLIF'S AREA]                |
    |                         |                       |
[STAFF HOLDER]          [WORK BENCH]          [POTION BOTTLES]
    
        [FLOATING CANDLES - suspended from ceiling]
        
                    [DOOR - Stage Left]
```

### Key Elements

#### 1. WARP CORE (Left Side)
- **Design:** Vertical cylinder, 7 feet tall
- **Material:** Clear acrylic tube with internal LED lighting
- **Lighting:** Pulsing blue/white LEDs (programmable)
- **Details:** 
  - Sci-fi technical panels around base
  - Magical runes etched on surface
  - Mist effect inside (optional - dry ice)
- **Construction:** Build or rent from prop house

#### 2. CAULDRON (Center-Right)
- **Design:** Large black cauldron on stand
- **Size:** 24-inch diameter
- **Effect:** Bubbling potion (dry ice + water + LED underlighting)
- **Safety:** Stable base, heat-free effect
- **Source:** Rent from theatrical supplier or purchase

#### 3. SPELL BOOK SHELF (Right Side)
- **Design:** Wooden bookshelf, 6 feet tall
- **Contents:**
  - 8-10 large leather-bound books
  - Titles visible: "Warp Drive Enchantments", "Transporter Spells", "Shield Charms for Starships"
  - Scrolls and parchments
  - Small potion bottles
- **Construction:** Modify existing bookshelf, add dressing

#### 4. STAFF HOLDER (Left Side)
- **Design:** Ornate stand (like a sword stand but for staff)
- **Material:** Wood or metal appearance
- **Details:** Starfleet insignia incorporated
- **Function:** Holds backup staff when not in use
- **Construction:** Build from wood, paint metallic

#### 5. WORK BENCH (Center)
- **Design:** Technical workstation with magical elements
- **Surface:** Scattered spell components, PADD devices, wands
- **Details:**
  - Floo powder containers
  - Mortar and pestle
  - Starfleet technical manuals
  - Wand repair tools
- **Construction:** Standard table with dressing

#### 6. FLOATING CANDLES (Ceiling)
- **Design:** 12-15 candles suspended at varying heights
- **Method:** 
  - Option A: Fishing line suspension (practical)
  - Option B: VFX (post-production)
  - **RECOMMENDED:** Practical with LED candles for safety
- **Lighting:** Flickering LED candles (battery operated)
- **Safety:** Secure rigging, no real flames

#### 7. BACK WALL
- **Design:** Combination of Star Trek and magical elements
- **Elements:**
  - Star charts and constellation maps
  - Technical readouts (Star Trek style)
  - Magical symbols and runes
  - Framed "Wizard of the Year" certificate
  - Hogwarts Starfleet Academy diploma
- **Material:** Printed backdrops, practical frames

#### 8. FLOOR
- **Design:** Star Trek-style grated metal floor
- **Material:** Painted plywood with grate pattern OR actual grating
- **Safety:** Non-slip surface for actors

#### 9. DOOR (Stage Left)
- **Design:** Star Trek-style sliding door
- **Function:** Practical sliding mechanism OR actors mime with sound effect
- **Sound:** Classic "whoosh" sound effect
- **Construction:** Frame with sliding panels

## SET 2: CONFERENCE ROOM (Secondary Set)

### Design Concept
**Classic Star Trek Conference Room**

### Dimensions
- **Width:** 14 feet
- **Depth:** 10 feet
- **Height:** 9 feet

### Layout

```
        [BACK WALL - Window with Starfield View]
                    
                    [CAPTAIN'S CHAIR]
                          (Head)
                            |
        [CHAIR]      [TABLE]      [CHAIR]
         (Clif)                    (Heidi)
        
                    [FIRST OFFICER]
                      (Standing)
                      
                    [DOOR - Stage Right]
```

### Key Elements

#### 1. CONFERENCE TABLE
- **Design:** Sleek, futuristic oval table
- **Size:** 8 feet long, 4 feet wide
- **Material:** Black or dark gray surface (glossy)
- **Details:** Embedded light strips (LED)
- **Construction:** Build from plywood, paint high-gloss

#### 2. CHAIRS
- **Design:** Star Trek-style command chairs
- **Quantity:** 4 (Captain, Clif, Heidi, 1 extra)
- **Source:** Rent from prop house or modify office chairs
- **Color:** Black or dark gray

#### 3. WINDOW/VIEWSCREEN (Back Wall)
- **Design:** Large window showing starfield
- **Size:** 8 feet wide, 5 feet tall
- **Method:** Green screen OR LED screen with starfield video
- **RECOMMENDED:** Green screen (easier for SNL workflow)
- **Frame:** Metallic Star Trek-style window frame

#### 4. WALLS
- **Design:** Clean, futuristic panels
- **Material:** Foam core or lightweight panels
- **Color:** Light gray with darker accents
- **Details:** 
  - Starfleet insignia on wall
  - Technical panels (non-functional)
  - Subtle lighting strips

#### 5. DOOR (Stage Right)
- **Design:** Star Trek sliding door (matching engine room)
- **Function:** Practical or mimed
- **Sound:** "Whoosh" sound effect

## Construction Timeline

### Week 1: Design & Build

**Monday:**
- Finalize designs
- Purchase materials
- Rent items (cauldron, chairs)

**Tuesday:**
- Build warp core structure
- Build conference table
- Construct wall panels

**Wednesday:**
- Build staff holder
- Build bookshelf modifications
- Paint all elements

**Thursday:**
- Install LED lighting (warp core, table)
- Rig floating candles
- Build door mechanisms

**Friday:**
- Assemble engine room set
- Assemble conference room set
- First look review

### Week 2: Dressing & Tech

**Monday:**
- Dress engine room (books, potions, props)
- Dress conference room (minimal dressing)
- Install green screen

**Tuesday:**
- Lighting setup (practical lights)
- Test warp core effects
- Test cauldron bubbling effect

**Wednesday:**
- Camera blocking with sets
- Adjust for camera angles
- Mark actor positions

**Thursday:**
- Full technical rehearsal with cast
- Test all practical effects
- Make adjustments

**Friday:**
- Final touches
- Safety check
- Set ready for shoot
